# 0002. `-k` で省略する検証の範囲

- ステータス: 承認
- 日付: 2026-11-07

## 背景

`-k` は、自己署名や期限切れの証明書でも中身を確認するためのオプション。rustls で検証を差し替える場合、証明書チェーンの検証だけでなく、ハンドシェイクの署名検証まで一括で省略することもできてしまう。

## 決定

`-k` で省略するのは、証明書チェーンとホスト名の検証だけにする。ハンドシェイクの署名（TLS 1.2 / 1.3）は、提示された証明書の公開鍵で引き続き検証する。

## 結果

- `-k` を付けても、相手が証明書に対応する秘密鍵を持っていることは確かめられる。
- 署名を偽造するサーバーに対しては、`-k` を付けてもエラーになる。
