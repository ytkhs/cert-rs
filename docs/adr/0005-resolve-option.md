# 0005. `--resolve` で接続先を差し替える

- ステータス: 承認
- 日付: 2026-11-07

## 背景

証明書を入れ替えるとき、DNS を新しいサーバーに向ける前に、新しいサーバーの証明書を確認したい。`/etc/hosts` を書き換える方法は手間がかかり、戻し忘れの危険もある。

## 決定

- `--resolve HOST:PORT:ADDR` を追加する。書式は curl の同名オプションに合わせる。IPv6 の ADDR は `[2001:db8::1]` のように角括弧で囲む。
- 一致する HOST:PORT への接続だけ、DNS を引かずに ADDR へ接続する。SNI と証明書のホスト名検証には HOST を使う。
- 出力の IP 欄には、実際に接続した ADDR を出す。
- PORT は 1〜65535 の数値として検証する。どのホストにも一致しなかった指定は、stderr に警告を 1 行出す（stdout は変えない）。

## 結果

- 切り替え前の新サーバーを、本番と同じホスト名で確認できる。
- 打ち間違いで DNS 経由の旧サーバーを見てしまっても、警告と IP 欄で気づける。
