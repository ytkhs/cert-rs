# 0007. 出力形式と終了コード

- ステータス: 承認（終了コードの扱いを [0011](0011-machine-readable-json.md) で補足）
- 日付: 2026-11-07

## 背景

cert は人が目で見る用途と、スクリプトや jq で処理する用途の両方で使う。複数ホストを一度に確認したとき、一部の失敗でほかの結果が失われると困る。

## 決定

- 出力形式は table（既定）、md、json の 3 つ。`-f` にほかの値を渡すとエラーにする。
- json は配列 1 行で、末尾に改行を付けない。`<` `>` `&` と U+2028 / U+2029 は `<` などにエスケープし、HTML やスクリプトに埋め込んでも安全にする。
- DNS 名の SAN がない場合とエラー行では、`sans` を `null` にする。組織名が空の場合は `organization` キーを省略する。
- 1 ホストの失敗は、その行の Error 欄に出すだけにする。終了コードは 0 のまま。ホストが 1 つも指定されないときだけ、stderr にメッセージを出して終了コード 1 にする。

## 結果

- 一部のホストが失敗しても、すべての結果が得られる。
- スクリプトで失敗を検出するには、終了コードではなく JSON の `error` を見る（README の jq の例を参照）。
